# Legacy dye scan split

TC4 registered every member of its sixteen-entry dye loop with `Sensus 1`.
Minecraft 1.20.1 has sixteen dedicated dye items, while four of the original
metadata identities also survive as separate materials: lapis lazuli, ink sac,
cocoa beans, and bone meal. Each JSON here deliberately has its own item scan
identity; the old metadata items must not disappear behind `forge:dyes`.
