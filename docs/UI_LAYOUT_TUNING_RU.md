# Ручная настройка UI

Этот файл фиксирует границу ответственности: расположение и размеры UI
задаёт автор проекта, а код применяет переданные значения. При следующих
правках достаточно прислать название экрана, элемента и новые числа.

## Система координат

- `X`: положительное значение двигает элемент вправо, отрицательное — влево.
- `Y`: положительное значение двигает элемент вниз, отрицательное — вверх.
- `Width` / `Height`: ширина и высота элемента.
- Все целочисленные координаты в Java — логические пиксели Minecraft GUI.
  Это не пиксели исходного PNG и не обязательно пиксели скриншота.
- При GUI Scale `4` перемещение на `1` логический пиксель обычно выглядит
  как перемещение примерно на `4` пикселя скриншота.
- Коэффициент `0.80F` означает 80% от размера родительского элемента.

Не следует менять `SOURCE_X`, `SOURCE_Y`, `SOURCE_WIDTH` и `SOURCE_HEIGHT`
для перемещения элемента на экране. Это координаты вырезаемого фрагмента
внутри PNG-атласа.

## Общий задний фон экранов

Все новые экраны Thaumcraft должны затемнять мир общим чёрным слоем с
`alpha = 0.6`, не изменяя прозрачность самой GUI-текстуры. Для этого перед
отрисовкой экрана нужно вызывать:

```java
ClassicScreenBackground.render(graphics, width, height);
```

Общее значение и цвет находятся в:

`src/main/java/com/thaumcraftmodern/client/screen/ClassicScreenBackground.java`

Не следует копировать `0x99000000` в каждый новый экран: изменение стандарта
должно выполняться в одном месте.

## Таумометр

Все значения собраны в блоке `Manual UI tuning block` в:

`src/main/java/com/thaumcraftmodern/client/ClientThaumometerOverlay.java`

### 3D-корпус и экран

- `FRAME_MAX_WIDTH` / `FRAME_MAX_HEIGHT` — максимальный экранный размер
  видимого 3D-корпуса.
- `FRAME_SCREEN_WIDTH_RATIO` — доля ширины экрана.
- `FRAME_SCREEN_HEIGHT_RATIO` — ограничение относительно высоты экрана.
- `FRAME_OFFSET_X` / `FRAME_OFFSET_Y` — сдвиг корпуса вместе с экраном,
  текстом и аспектами.

Золотой корпус теперь является настоящей моделью `scanner.obj`. Синий
`scanscreen.png` назначен отдельному материалу и плоскости внутри OBJ, поэтому
его положение относительно рамки настраивается координатами четырёх последних
вершин в `textures/models/scanner.obj`, а не GUI-коэффициентами.

`MODEL_VISIBLE_WIDTH` / `MODEL_VISIBLE_HEIGHT` описывают занятую моделью долю
стандартной области предмета `16×16`. Их следует менять только если после
изменения геометрии OBJ экранный размер перестал совпадать с `FRAME_MAX_*`.

### Текст, аспекты и прогресс

- `READOUT_X_RATIO` / `READOUT_Y_RATIO` — начало рабочей области внутри рамки.
- `READOUT_WIDTH_RATIO` / `READOUT_HEIGHT_RATIO` — её размер.
- `PROGRESS_TEXT_OFFSET_Y` — вертикальный сдвиг надписи сканирования.
- `PROGRESS_BOTTOM_INSET` — расстояние полосы прогресса от низа рабочей
  области. Чем меньше число, тем ниже полоса.

## Таумономикон

Основные размеры собраны в начале:

`src/main/java/com/thaumcraftmodern/client/screen/ThaumonomiconScreen.java`

- `TREE_INNER_X/Y/WIDTH/HEIGHT` — область фона внутри деревянной рамки.
- `BACKGROUND_SOURCE_X/Y` — положение вырезки внутри фоновой текстуры.
- `RESEARCH_NODE_SIZE` — размер рамки узла исследования.
- `RESEARCH_ICON_SIZE` — размер предмета внутри узла.
- `CATEGORY_TAB_SIZE` / `CATEGORY_ICON_SIZE` — вкладки категорий.
- `RECIPE_*` — сетка рецепта, шаг ячеек и положение результата.

Положение самих исследований задаётся без изменения Java-кода в:

`src/main/resources/data/thaumic_reborn/thaumcraft/research/*.json`

Поля `x` и `y` считаются от центра дерева:

- `x: 0, y: 0` — центр;
- положительный `x` — вправо;
- отрицательный `x` — влево;
- положительный `y` — вниз;
- отрицательный `y` — вверх.

## Формат задания значений

Для однозначной правки можно присылать значения так:

```text
Экран: Таумометр
Элемент: 3D-корпус вместе с экраном
FRAME_MAX_WIDTH: 336
FRAME_MAX_HEIGHT: 292
FRAME_OFFSET_X: 0
FRAME_OFFSET_Y: 0
```

Или для исследования:

```text
Исследование: first_discovery
x: 24
y: -16
```

Если известен только желаемый сдвиг на скриншоте, нужно дополнительно указать
текущий `GUI Scale`. Тогда его можно перевести в логические GUI-пиксели.
